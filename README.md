# 🧱 BrickFlow — Universo de Blocos de Montar

O **BrickFlow** é um gerenciador de tarefas avançado e lúdico construído inteiramente com **HTML5, CSS3 e JavaScript puro (Vanilla JS)**. Toda a interface simula um universo tridimensional de blocos de montar, com suporte a minifiguras originais articuladas e todas as especificações do exercício TaskFlow.

## 🚀 Funcionalidades
- **Dashboard de Produtividade:** Acompanhamento dinâmico de estatísticas de tarefas e barra de progresso temática estilo réguas de blocos.
- **Quadro Kanban 3D:** Colunas categorizadas (*A Fazer*, *Em Andamento*, *Concluídas*) com suporte completo a **Drag and Drop**.
- **Gerenciamento Completo (CRUD):** Cadastro, edição, exclusão e alerta automático para tarefas em atraso.
- **Pesquisa e Filtros Simultâneos:** Filtre instantaneamente por palavra-chave do título, prioridade (Baixa, Média, Alta) ou status.
- **Persistência Local:** Salva e recupera todas as alterações no `localStorage` do seu navegador.
- **Recursos Extras:** Modo Escuro (Noturno) e Exportação de dados para ficheiro `.json`.

## 🛠️ Tecnologias
- **HTML5**
- **CSS3** (Gradientes 3D, Flexbox, CSS Grid e animações)
- **JavaScript (Vanilla / ES6)**

## 📂 Como Executar
1. Descompacte o ficheiro ZIP.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Não requer qualquer backend, dependência ou servidor!
